# Reflexão Crítica - Projeto Integrador (Git e GitHub)

## 1. Três Conceitos de Maior Complexidade Assimilados
* **Gerenciamento de Ramificações (Branches) e Fluxo de Merge:** Compreender como o isolamento de fluxos de trabalho em paralelo protege o branch principal (`main`) e permite o desenvolvimento seguro de novas funcionalidades sem corromper a base estável.
* **Resolução e Prevenção de Conflitos:** O entendimento prático de como o Git gerencia alterações simultâneas no mesmo arquivo e os mecanismos necessários para arbitrar e resolver divergências de código.
* **Uso de Conventional Commits:** A estruturação semântica do histórico de versões (`feat`, `style`, `docs`), transformando o log de commits em uma documentação viva e legível do projeto.

## 2. Três Recursos de Aplicação Imediata no Cotidiano Técnico
* **Rastreabilidade e Histórico via Log:** Facilidade para auditar alterações anteriores, identificar quando um comportamento foi introduzido e auditar o código de forma pontual.
* **Isolamento de Tarefas com Branches Temporárias:** Capacidade de criar ambientes limpos para testar novas ideias ou correções rápidas com a segurança de descartar ou integrar facilmente via Pull Request.
* **Documentação Viva com README.md e Issues:** O mapeamento e a organização sistemática de tarefas e requisitos diretamente no ecossistema do **[GitHub](https://github.com/andersonobre-cmd/calculadora-otimizacao/pulls)**.
